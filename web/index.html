ADD A SERVER · SETUP NOTES

Start with a text log.

The current agent runs on a machine you manage. It reads new lines from a regular file and forwards matching lines to your DIDS server.

01
Build the agent on the server
cd common/agent && make
02
Point it at a readable text log
./agent demo /path/to/app.log 127.0.0.1 9000

! The agent begins at the end of the file. It detects only new lines. The server must be reachable at the address you provide.

macOS needs a regular text file.

This agent cannot read Apple’s unified logging system or Console.app directly. For a safe local preview, create a file and append synthetic log lines.

touch ~/dids-demo.log
./agent demo ~/dids-demo.log 127.0.0.1 9000

! Don’t point a demo at personal or production logs. Matching lines are forwarded in full.

Setup is manual in this prototype.
